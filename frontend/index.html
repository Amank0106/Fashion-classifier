About the model

A custom CNN with two convolution blocks and three fully connected layers, trained from scratch on Fashion-MNIST.

Architecture

  1. Input image1 × 28 × 28

  3. Conv2D 32 → 64, 3 × 3, same padding, BatchNorm, ReLU, MaxPool 2 × 264 × 7 × 7
  4. Flatten3136
  5. Linear 3136 → 128, ReLU128
  6. Linear 128 → 64, ReLU64
  7. Linear 64 → 10, output logits10
